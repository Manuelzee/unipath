"Do not display annual tuition or annual cost figures anywhere in the student-facing app." Keep the existing UniPath AI design and subscription plans.

**Why:** The user explicitly requested this change, superseding the earlier tuition display and budget-filter requirements.

**How to apply:** Do not add school-price displays or annual budget controls to cards, details, discovery, profiles, or guidance. Subscription pricing remains unchanged.

Use official sources and identify the source and last-updated date. Never invent missing information. Link to official school admissions and financial aid pages when supplied; otherwise clearly label the official-homepage fallback.

**Why:** Scorecard does not contain complete current admissions requirements or scholarship opportunities, and the user requires honest coverage.

**How to apply:** Do not claim data has been imported until the database is working correctly. Distinguish source reporting dates, directory import dates, and current verification. The owner is a beginner; handle setup where possible and give exact file/upload instructions.
